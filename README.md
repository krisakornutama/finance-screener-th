# Finance Screener TH 🇹🇭📈

S&P 500 stock screener — Dividend / Growth / Momentum / Value (คอมเมนต์ไทย)

> ⚠️ ไม่ใช่คำแนะนำการลงทุน (DYOR). ข้อมูลจาก `yfinance` + Wikipedia อาจดีเลย์/โดน rate-limit.

## ลากวางแล้วรันเลย

```bash
pip install -r requirements.txt
python "Master Screener Dividend+Grow+Graph.py"
# Full Scan ~15-20 นาที / Test: เปิดไฟล์แล้วตั้ง RUN_FULL_SCAN=False
```

ไฟล์อื่นๆ รันเดี่ยวๆ ได้เหมือนกัน: `Dividend Investor.py`, `Pure Growth.py`, `Momentum Investing.py`, `Value Investing.py`, `Growth at a Reasonable Price.py`, `Trade Finder.py`, `Shares.py`, `ALL IN.py`, `spy.py`
